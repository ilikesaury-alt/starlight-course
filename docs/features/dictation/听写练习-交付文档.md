## 1. 功能概述

给三年级上册孩子用的**英语听写练习**：听发音 → 把单词写出来（或从三个拼法里选出对的）→ 立刻得到反馈，写错时**教你把这个声音拆成字母**（自然拼读）。

- **面向谁：** 已有一两年听力启蒙、但三年级开始做单词听写时"很简单的词也不会写"的孩子（听/说没问题，缺的是"音→形"的拼写能力）。
- **解决什么：** 补上"听音→写词"的缺口，并把音素与字母的对应显式教出来，而不是让孩子继续刷"看图选词"。
- **本版本包含：** 三年级上册英语（外研版）全部单元的单词 + 附录剧本词；听音写词（一字一盒 + 屏幕字母盘）/ 三选一两种模式；音素格子 + 金字塔拼写提示；错词进错题本、每词结果进智能复习；一轮结束的会话报告（正确率环 / 星星 / 错词清单）。
- **本版本不包含：** 手写字母输入；跨其他课程（Starlight / Fly Guy / Rocket Girl）取词；按复习到期自动选词。

## 2. 使用说明

### 入口
首页 → 青绿色卡片 **「✍️ 听写练习」**（在 Starlight 主课下方）。
或直接访问 `#/dictation`。

### 操作步骤
1. **选一种玩法**（两张卡片二选一，选中的卡会打勾）
   - `✍️ 听音写词`：听发音，把字母一个一个写进方格里。**核心训练，推荐。**
   - `🔍 三选一`：听发音，从三个拼法里选正确的。**起步更轻松**，适合刚上手。
2. **选范围**
   - 默认「全部单元」；也可只勾若干单元/剧本。
   - 勾选 `只练错题本里的词`：只用错题本里 `英语` 模块的错词（括号里显示当前数量）。
3. **选词的长短**
   - `全部` / `短词（≤4 字母）` / `长词`。
   - 建议先用短词建立信心。
4. **点「🚀 开始听写」** —— 每轮最多 10 个词（按当前范围随机抽）。
5. **逐个作答**（顶部有进度条与 `✕ 退出`）
   - 每换一个词会**自动朗读一遍**；页面上另有 1 个大按钮重听 + 1 个 `慢速` 按钮，可反复听。
   - 听音写词：
     - 答案区是**一字一盒**：一个字母一个方格，当前要写的那格带光标。
     - 输入方式二选一：直接敲键盘，或点下面的 **26 键字母盘**（含 ⌫ 删除）。两者可以混用。
     - 带撇号的词（如 `let's`）撇号是**固定装饰格**，孩子只写字母即可（打 `lets` 也算对）。
   - 三选一：点你认为拼对的选项（选项前有 A/B/C 标号）。
6. **反馈规则（两试一揭）**
   - 第一次写错 → 横幅提示「差一点点，再试一次！」+ **逐格标色**：写对的字母变绿、写错的变红、还没写的字母变虚线格，并给出「第 n 个字母不对 / 还差几个字母」的人话提示；可点「✏️ 清空重写」或直接改。
   - 第二次仍错 → 揭晓正确答案，并展示音素拆分布局。
   - 写对 → 横幅「太棒了，拼得完全正确！」+ 逐格全绿，约 1.1s 后自动进入下一个词。
7. **一轮结束 → 会话报告**
   - 正确率（环形图，最大数字）、答对几个、最长连对、要再练几个、获得星星（逐颗弹出）。
   - 列出本轮写错的词（已自动进错题本）。
   - 可「🔁 再来一轮」「🎚️ 换个范围」「📋 错题本」「🧠 智能复习」。
8. **中途想放弃** → 点右上角 `✕ 退出` 立刻回设置页（本轮记录随之丢弃，不结算星星、不再弹确认）。

### 自然拼读提示（写不出来时）
- **💡 我拼不出来，给点提示**：一上来就能点，点开看音素格子（它是提示，不是判卷依据）。
- 第一次写错后，提示区会**自动展开**，不用再去找入口。
- **音素格子**：把单词按"声音段"切开，每格可单独点 🔊 听（如 `ch` / `i` / `ck`）。
- **金字塔拼写**：`c` → `ca` → `cat`，点「多给一个字母 ▸」逐阶展开。

## 5. 已知问题与注意事项

1. **"第一次错、第二次改对"仍计为错。**
   口径：**首次能否独立写对**才是真实掌握度。改对后 UI 给鼓励文案（不打击），但该词仍记一次错、进错题本。这是有意设计，非缺陷。
2. **音素切分是轻量规则，不是语言学精确切分。**
   例：`cake → c / a / ke`、`apple → a / p / p / le`。定位是"把声音段对应到字母段"的**教学提示**，不声称严格音素学。若日后要更严谨，需引入发音词典（成本高）。
3. **干扰项由原词变形生成**，技巧是"换一个字母/双写/换位"。个别极短词（如 2 字母词）可变形空间小，可能凑不满 3 个选项——此时会少于 3 个而非塞乱码。
4. **语音依赖既有兜底链**（Kokoro→云 TTS→WebSpeech）。若设备全程无声，属既有语音链路问题（见 `AGENTS.md` 语音章节），不是本功能特有。
5. **每轮最多 10 词**，范围再大也只抽 10 个；重复练习同一范围会抽到不同词（随机）。
6. **中途 `✕ 退出` 直接丢弃本轮**，不结算星星、不弹确认。当前取舍是「孩子被卡住时要能一键脱身」；若之后发现误触丢成绩，再补一层「确实要退出吗」。
7. **撇号 / 空格是装饰格，不是可写格。**
   - `Ms Smart` 这类含空格的词：孩子只需按字母顺序写（`mssmart` 即判对），空格在字母盒里显示为一个小间隙。
   - `let's` 这类含撇号的词：撇号固定显示，打 `lets` 也判对。**注意**：eng3a 词表里没有含撇号的单词（撇号只出现在例句里），这条分支目前仅在单测里验证，尚无真实词触发。
8. **报告页「要再练」= 本轮写错的词数**，与下方错词清单同源；不是错题本总数。

## 6. 部署与回滚要点

- **部署：** 与既有前端一致（GitHub Actions → Pages / Electron 打包），无额外步骤、无环境变量、无新增资源文件。
- **回滚：** 纯前端增量功能，回滚即回退相关文件；不涉及数据迁移，用户既有进度（`localStorage` 键 `starlight-course`）不受影响。
- **无 SW 缓存特殊处理**：沿用既有 `skipWaiting: true`；若用户看到旧版本，刷新一次即可。
