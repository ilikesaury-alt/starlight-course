## 1. 功能概述

给三年级上册孩子用的**英语听写练习**：听发音 → 把单词写出来（或从三个拼法里选出对的）→ 立刻得到反馈，写错时**教你把这个声音拆成字母**（自然拼读）。

- **面向谁：** 已有一两年听力启蒙、但三年级开始做单词听写时"很简单的词也不会写"的孩子（听/说没问题，缺的是"音→形"的拼写能力）。
- **解决什么：** 补上"听音→写词"的缺口，并把音素与字母的对应显式教出来，而不是让孩子继续刷"看图选词"。
- **本版本包含：** 三年级上册英语（外研版）全部单元的单词 + 附录剧本词；听音写词 / 三选一两种模式；音素格子 + 金字塔拼写提示；错词进错题本、每词结果进智能复习；一轮结束的会话报告。
- **本版本不包含：** 手写字母输入；跨其他课程（Starlight / Fly Guy / Rocket Girl）取词；按复习到期自动选词。

## 2. 使用说明

### 入口
首页 → 青绿色卡片 **「✍️ 听写练习」**（在 Starlight 主课下方）。
或直接访问 `#/dictation`。

### 操作步骤
1. **选练习模式**
   - `✍️ 听音写词`：听发音，把完整单词写出来。**核心训练，推荐。**
   - `🔍 三选一`：听发音，从三个拼法里选正确的。**起步更轻松**，适合刚上手。
2. **选范围**
   - 默认「全部单元」；也可只勾若干单元/剧本。
   - 勾选 `只练错题本里的词`：只用错题本里 `英语` 模块的错词（括号里显示当前数量）。
3. **选词的长短**
   - `全部` / `短词（≤4 字母）` / `长词`。
   - 建议先用短词建立信心。
4. **点「🚀 开始听写」** —— 每轮最多 10 个词（按当前范围随机抽）。
5. **逐个作答**
   - 屏幕上有 2 个 🔊：正常语速 / 慢速，可反复听。
   - 听音写词：键盘输入，或点屏幕字母盘（含 ⌫ 删除）。
   - 三选一：点你认为拼对的选项。
6. **反馈规则（两试一揭）**
   - 第一次写错 → 红字提示，可看音素格子，**还能再改一次**。
   - 第二次仍错 → 揭晓正确答案，并展示音素拆分布局。
   - 写对 → 绿字鼓励，自动进入下一个词。
7. **一轮结束 → 会话报告**
   - 正确率 %、答对几个、最长连对、获得星星。
   - 列出本轮写错的词（已自动进错题本）。
   - 可「🔁 再来一轮」「🎚️ 换个范围」「📋 错题本」「🧠 智能复习」。

### 自然拼读提示（写不出来时）
- **💡 我拼不出来，给点提示**：一上来就能点，先看音素格子，不直接泄答案。
- **音素格子**：把单词按"声音段"切开，每格可单独点 🔊 听（如 `ch` / `i` / `ck`）。
- **金字塔拼写**：`c` → `ca` → `cat`，点「多给一个字母 ▸」逐阶展开。

## 5. 已知问题与注意事项

1. **"第一次错、第二次改对"仍计为错。**
   口径：**首次能否独立写对**才是真实掌握度。改对后 UI 给鼓励文案（不打击），但该词仍记一次错、进错题本。这是有意设计，非缺陷。
2. **音素切分是轻量规则，不是语言学精确切分。**
   例：`cake → c / a / ke`、`apple → a / p / p / le`。定位是"把声音段对应到字母段"的**教学提示**，不声称严格音素学。若日后要更严谨，需引入发音词典（成本高）。
3. **干扰项由原词变形生成**，技巧是"换一个字母/双写/换位"。个别极短词（如 2 字母词）可变形空间小，可能凑不满 3 个选项——此时会少于 3 个而非塞乱码。
4. **语音依赖既有兜底链**（Kokoro→云 TTS→WebSpeech）。若设备全程无声，属既有语音链路问题（见 `AGENTS.md` 语音章节），不是本功能特有。
5. **每轮最多 10 词**，范围再大也只抽 10 个；重复练习同一范围会抽到不同词（随机）。

## 6. 部署与回滚要点

- **部署：** 与既有前端一致（GitHub Actions → Pages / Electron 打包），无额外步骤、无环境变量、无新增资源文件。
