# 「桌面化」交付文档（v0.1.0）

> 受众：测试同学与使用方（家长）。不涉及代码实现细节；开发侧口径见 `CONTEXT.md` 与 `AGENTS.md`。
> 状态：2026-10-18 验收通过（7/7），对应安装包 `release/Starlight 学习伙伴 Setup 0.1.0.exe`（86MB）。

## 1. 功能概述

把原本只能开网页使用的《Starlight 学习伙伴》做成了 **Windows 桌面应用**：双击安装包安装后，双击桌面图标即可使用，无需浏览器、无需联网地址。孩子的学习进度保存在本机，日常学习**断网也能用**（点读发音依赖网络，见已知问题）。

- **面向谁**：家里用 Windows 电脑陪孩子学英语的家长/孩子。
- **本版本不包含**：旧学习进度迁移（桌面版从零开始记进度）、自动更新、系统托盘、Mac/Linux 版、图标定制、麦克风跟读。

## 2. 使用说明

### 安装与启动（使用者视角）

1. 双击 `Starlight 学习伙伴 Setup 0.1.0.exe`，按提示完成安装（标准 NSIS 安装向导，可下一步到底）。
2. 安装完成后桌面出现「Starlight 学习伙伴」图标，双击打开。
3. 窗口尺寸 1280×800，界面与浏览器版完全一致：选单元 → 进课 → 点词/翻页/做 quiz → 星星与进度自动保存在本机。

### 开发/测试侧命令

| 命令 | 用途 |
|---|---|
| `npm run electron:dev` | 起桌面壳开发态（自动并发起 Vite + Electron，探测 dev server） |
| `npm run electron:build` | 打包 Windows NSIS 安装包（产物在 `release/`） |
| `npm run electron:smoke` | 构建 + 加载 + 程序化冒烟验收（输出 JSON 后退出），用于快速判断壳是否健康 |
| `npm run build` / `npm run e2e` | 网页版构建与 E2E，流程不变，**不受桌面化影响** |

## 3. 权限/配置变更

- **无新增权限点/角色**：纯壳改动，业务代码零修改；无后端、无账号体系。
- 构建机配置要求（一次性）：
  - 国内网络需镜像环境变量 `ELECTRON_MIRROR`、`ELECTRON_BUILDER_BINARIES_MIRROR`（构建脚本已默认注入 npmmirror，可用同名 env 覆盖）。
  - **Windows 必须开启「开发者模式」**，否则 electron-builder 解压 winCodeSign 时因符号链接报「客户端没有所需的特权」导致打包失败（脚本已内置预解压自愈，但开发者模式仍是前置条件）。
- 数据存储：壳内使用独立持久分区（`partition: 'persist:starlight'`），与浏览器 localStorage 互不相通。

## 4. 测试指引

环境：Windows 10/11 x64，无需账号。安装包见 `release/`。冒烟探针（下表 1/3/4 条）已由 `npm run electron:smoke` 程序化覆盖；其余需人工走查。

| # | 用例 | 预期 | 覆盖方式 |
|---|---|---|---|
| 1 | 安装后启动，首页正常渲染 | 非白屏，课程列表可见 | 已自动化（smoke：`#root` 非空） |
| 2 | 点单词、点句子发音 | 能出声（真实音质需人工听） | 链路已自动化（主进程验百度 TTS 返回 `audio/mpeg`），**发声真实性需人工听** |

| 4 | 进度持久化 | 做一课 quiz 拿星 → 完全关闭应用 → 重开，星星与进度仍在 | 已自动化（smoke 写入/回读断言）+ 建议人工复验一次 |
| 5 | 断网使用 | 断网打开应用：页面、已缓存内容可用；发音降级（Kokoro 需满足条件，否则静默退 WebSpeech/无云音），不得崩溃 | 人工 |

| 8 | 卸载重装 | 卸载后重装，进度**会清空**（数据在应用数据目录，卸载随目录删除，视安装器选项而定） | 人工 |

## 5. 已知问题与注意事项

1. **旧学习进度不会迁移**（已确认的决策）：孩子在浏览器版积累的进度，桌面版读不到，首次打开是全新进度。请提前向使用方说明，避免「进度丢了」的误解。
2. **麦克风跟读在桌面版不可用**：Electron 内语音识别必挂（需 Google 语音后端）。跟读入口默认隐藏，不影响其他功能。
3. **发音依赖网络**：本机无 WebGPU（老核显）时点读走云 TTS/有道/系统语音，断网时发音质量下降甚至无声；「完全离线可用」仅在满足 WebGPU/Vulkan 的机器上成立。
4. **首次启动可能白屏几秒后恢复**（冷启动加载本地资源），属正常；持续白屏请跑 `npm run electron:smoke` 收集 JSON 反馈。
5. 卸载重装/清应用数据 = 进度清空（无导出/导入功能）。

## 6. 部署与回滚要点

- **分发方式**：手动分发 `release/Starlight 学习伙伴 Setup 0.1.0.exe`（无自动更新、无应用商店上架）。
- **部署** = 让使用者跑一次安装向导，无服务端、无数据库、无配置下发。
- **回滚**：直接卸载桌面版；网页版（GitHub Pages PWA）全程未受影响，随时可回到浏览器使用，浏览器版旧进度原样保留在原浏览器里。
- 重打包时若失败，优先检查：① 开发者模式是否开启；② `release/` 与 electron 缓存目录残留（脚本幂等自愈，删除缓存重跑即可）。
