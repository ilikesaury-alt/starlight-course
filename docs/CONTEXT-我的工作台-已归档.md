## 要解决的问题

家长打开应用的第一件事是**带孩子找到正在学的课程、进入下一节预习**；复习极少用。现有首页把「今日复习」放在视觉首位、课程入口只有静态宫格（进度徽章但没有「下一课」直达），主次错位。目标：把首页重构为「我的工作台」——首屏即「下一步学什么」，一键直达预习。

## 范围（In / Out）

**In**
- 首页 `/` 重构为工作台布局（替换现 Home 结构；`/` 路由、底部导航不变）
- 课程卡升级：每模块卡带「下一课」直达行（5 个模块：语文 / 英语3A / Starlight / Rocket Girl / Fly Guy）
- 顶部概览条：🔥 连击天数 + 今日到期复习**小**入口（`todayDue=0` 时不出现）
- 底部：近 7 天迷你热力条
- 新增 store 状态 `dailyLog`（按日×模块聚合计数），persist v8→v9 迁移

**Out（暂不做，可另开需求）**
- 全年 GitHub 式大热力图、复习趋势预测曲线、掌握度分级、AI 推荐
- 「继续上次」独立区块（被每卡直达行覆盖）
- 错题本 / 拓展词管理进工作台（仍走原入口）
- `/courses` 页与底部导航改动；任何后端 / 同步

## 已确认方案（Step 2 think）

### 第一性原理

工作台的本质不是数据面板，是**「下一步学什么」的一键直达器**：家长打开 → 看到每门课学到哪、下一节是什么 → 点一下进预习。复习、统计全是配角。现有 `TodayTasks` 已实现「每模块找下一节未完成课」的核心逻辑，重构以它为种子，而不是重写。

### 方案对比

| 方案 | 做法 | 收益 | 代价 | 风险 |
|------|------|------|------|------|
| A 仪表盘优先 | 热力图/统计占首屏 | 数据一目了然 | 与「找课预习」主诉求错位 | 用户已明确少用复习 → 否决 |
| **B 直达器优先（推荐）** | 课程卡升级为「带下一课直达」的工作台；复习小入口；连击+7日热力条占底部一行 | 首屏即「下一步」；改动集中在 Home + dailyLog | 首页 E2E 需同步改 | 见高风险点 |
| C 最小改动 | 只调 TodayTasks 顺序 | 最省 | 不满足「改造为工作台」 | — |

### 关键设计

1. **页面结构**（`Home.tsx` 重写）
   - 顶部概览条一行：🔥 连击 N 天 + 今日到期复习小入口（`todayDue=0` 时不显示复习）
   - 主区：5 个课程模块卡（复用 `CourseEntries` 的卡片与徽章），每卡新增**「继续学 · 下一课：Lesson X-X」直达行**（`TodayTasks` 的 next-lesson 逻辑抽取为 hook `useNextLessons()`，口径原样搬，故事模块仍动态 import）
   - 底部一行：近 7 天迷你热力条（`dailyLog` 现算，空数据渲染空条不出错）
   - 快捷行（字母表/进度）保留；hero 区压缩为单行标题
2. **dailyLog 状态**（store，persist v8→v9）
   - `dailyLog: Record<'YYYY-MM-DD', Record<ModuleId, number>>`，按天×模块聚合计数
   - 写入：8 个现有完成 action（`markPreviewDone / markLessonDone / markQuizDone / markStoryDone / markRecite / markChineseQuiz / markChineseDone / recordReview`）统一走一个 `touchDailyLog(module)` helper **在 store 内埋点**，组件零直接写状态
   - 迁移：migrate 对旧数据补 `dailyLog ?? {}`，不碰任何既有字段；体量：按天聚合一年 365 条小 JSON，无需 cap
   - 连击定义：当日任一模块计数 ≥1 即「学习日」；连击 = 从今天（或昨天）往回连续学习日数
3. **不做的**（奥卡姆剃刀已删）：全年大热力图、预测曲线、掌握度分级、AI 推荐、「继续上次」独立区块、后端/同步

### 对抗性审查（找能推翻核心假设的反例）

| 反例 | 风险 | 处置 |
|------|------|------|
| 5 张卡每张多一行直达 → 卡片变高，首屏看不见全部课程 | 违背「打开首页找到课程」 | 直达行做卡内单行紧凑条；E2E 断言 5 卡首屏可见 |
| 各模块「下一课」口径不同（Starlight 按 unit→lesson，故事按 slug） | hook 泄漏复杂度 | 逻辑从 TodayTasks 原样抽取不改口径；故事模块保持动态 import |
| home/chinese/eng3a/review 4 个 spec 都走首页选择器 | 改版即红 | 同步更新；以 `npm run e2e` 全绿为验收 |
| persist v8→v9 迁移丢旧进度 | 高危 | migrate 只补默认空对象；E2E 加旧版本数据加载用例 |
| recordReview 高频调用 | 状态抖动 | 同一天重复 touch 只更新同一条聚合值，无数组 append |
